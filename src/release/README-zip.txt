KAISERREICH COLLECTION __VERSION__
==============================
Every Kaiserreich from 0.8.4a to 1.7, each running on the Hearts of Iron IV
version it was made for. Free and fan-made.
Source code and updates: https://github.com/Chessiehawk/Kaiserreich-Collection

__STEP0__1. Right-click this zip > "Extract All..." (don't run it from inside the zip).
2. Have Steam open and logged in. Hearts of Iron IV must be installed.
3. Double-click "Kaiserreich Collection.exe".
4. Click the Kaiserreich you want (the picture tiles), then click PLAY.

The FIRST time you play a version it installs itself:
   - Steam closes, reopens and downloads that old game version (about 1 GB).
     That is normal - don't close the launcher window, and don't use Steam
     for those few minutes.
   - The game is copied into its own folder (about 6-9 GB, on your D: drive
     if you have one), then Steam is put back how it was.
   After that, that version starts instantly.

A "Kaiserreich Collection" shortcut appears on your Desktop after the first
PLAY. Use that from then on. Older copies of the launcher in your Downloads
folder or on your Desktop go to the Recycle Bin, so they can't put an old
version back.

"Install all" installs all 16 versions in one go - roughly 110 GB and a few
hours. You don't need it; PLAY installs just the one you picked.

Multiplayer: everyone must pick the SAME Kaiserreich tile and the same DLC
(or tick "No DLC" - the easiest way to match). Different DLC = "out of sync"
the moment someone joins. On the oldest versions (HOI4 1.5-1.7) the launcher
really switches unticked DLC off, so "No DLC" works there too.

WASD map movement (tick it under the PLAY button - it is off unless you
turn it on): W/A/S/D scroll the map. Opening the console (the key under Esc)
pauses it so you can type; closing the console, or Esc, brings it back.
For chat and save names, press F11 to turn it off and on.

Custom game "ACW: MacArthur" (the MacArthur tile): click it so it says ON,
pick your Kaiserreich, then PLAY. In the game either
   - start a new game: Custom Game Rules > Load Preset >
     "American Civil War - MacArthur", or
   - skip ahead: Load Game > "ACW_MacArthur_KR_<version>" - a ready save as
     MacArthur's USA around the time the country breaks apart.
__SAVES__

If Windows shows a blue box saying "Windows protected your PC":
   click "More info", then "Run anyway". (It says that for any program that
   isn't from a big company.) The program isn't signed, so some antivirus
   tools may also flag it as "unknown" - it only runs as your normal user
   and never asks for admin.
